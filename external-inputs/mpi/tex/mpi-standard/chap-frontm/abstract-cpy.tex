   This document describes the Message-Passing Interface (\mpi/)
   standard, version 5.1.

   The \mpi/ standard includes point-to-point message-passing,
   collective communications, group and communicator concepts,
   process topologies, environmental management,
   process creation and management, one-sided communications,
   extended collective operations, external interfaces, I/O,
   some miscellaneous topics, and multiple tool interfaces.
   Language bindings for C and Fortran are defined.

Historically, the evolution of the standard is:
\begin{itemize}
\item \MPIIDOTO/ (May 5, 1994): Initial release.
\item \MPIIDOTI/ (June 12, 1995): Minor updates and bug fixes.
\item \MPIIDOTII/ (July 18, 1997): Several clarifications and additions.
\item \MPIIIDOTO/ (July 18, 1997): New functionality and all the
      clarifications and additions from \MPIIDOTII/.
\item \MPIIDOTIII/ (May 30, 2008): For historical reasons, combining the
      \MPIIDOTI/, \MPIIDOTII/, and several errata documents into one combined
       document.
\item \MPIIIDOTI/ (June 23, 2008): Combining the previous documents.
\item \MPIIIDOTII/ (September 4, 2009): Additional clarifications and seven
       new routines.
\item \MPIIIIDOTO/ (September 21, 2012): Extension of \MPIIIDOTII/.
\item \MPIIIIDOTI/ (June 4, 2015): Clarifications and minor extensions to
      \MPIIIIDOTO/.
\item \MPIIVDOTO/ (June 9, 2021): Significant new features beyond \MPIIIIDOTI/.
\item \MPIIVDOTI/ (November 2, 2023): Clarifications and minor extensions
to \MPIIVDOTO/.
\item \MPIVDOTO/ (June 5, 2025): Significant new features beyond \MPIIVDOTI/.
\end{itemize}
