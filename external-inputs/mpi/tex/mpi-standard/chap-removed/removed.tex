\section{Removed \texorpdfstring{\MPII/}{MPI-1} Bindings}
\label{sec:rm-mpii}

\subsection{Overview}
\label{subsec:rm-mpii-intro}

The following \mpii/ bindings were deprecated as of \mpiii/ and were removed in \mpiiii/.
They may be provided by an implementation for backwards compatibility, but are not required.
Removal of these bindings affects all language-specific definitions thereof.  
Only the language-neutral bindings are listed when possible.

\section{C++ Bindings}
\label{sec:rm-cpp}


\deprecatedsep


The C++ bindings were deprecated as of \texorpdfstring{\MPIIIDOTII/}{MPI-2.2}.
The C++ bindings were removed in \texorpdfstring{\MPIIIIDOTO/}{MPI-3.0}.
The namespace is still reserved, however,
and bindings may only be provided by an implementation
as described in
the \texorpdfstring{\MPIIIDOTII/}{MPI-2.2} standard.
